# Wanjiru Surprise 💖

A special surprise website for Wanjiru (Smiley).

## Features
- ✨ Hero section with custom animations
- 💃 "The One & Only" cards
- 📸 Photo gallery (placeholders included)
- 💌 Interactive "Tap to Reveal" messages
- 😂 Kikuyu IT-themed jokes
- 🎯 Quiz: "How Well Do You Know Yourself?"
- 🎮 Mini-game: Catch the Hearts
- 📜 Personalized Love Letter

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## Deployment
Deployed on Netlify.
